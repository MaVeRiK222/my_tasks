### Backend часть "Мои задачи"

#### Стэк: Laravel 11, Sanctum (API auth), PHP 8.2, MySQL, Redis

---

#### Как поднять:

Создать .env в корне либо скопировать .env.example в .env

docker-compose up --build

---

#### Аутентификация

Для начала работы нужно получить куки по пути: /sanctum/csrf-cookie

Затем создать пользователя через /api/register

И получить токен через /api/login

---

## 📋 API Endpoints

### 🔐 Аутентификация

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/register` | Зарегистрироваться |
| POST | `/api/login` | Аутентифицироваться |

### 📝 Задачи

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/tasks` | Получить все задачи текущего пользователя |
| POST | `/api/tasks` | Создать задачу |
| PUT | `/api/tasks/{id}` | Обновить задачу |
| DELETE | `/api/tasks/{id}` | Удалить задачу |

### ⏰ Напоминания

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/tasks/{id}/reminder` | Установить или изменить напоминание |
| DELETE | `/api/tasks/{id}/reminder` | Удалить напоминание |
